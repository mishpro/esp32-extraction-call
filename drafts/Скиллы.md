# Guidecaller — Агентские скиллы для разработки

**Дата:** 2026-11-02
**Как выбиралось:** `npx skills find <запрос>` по каждой зоне проекта, затем проверка по трём критериям — число установок, звёзды репозитория, результат security-аудита на skills.sh.

Правило отбора: **устанавливать скилл, только если репозиторий даёт понятный вклад в проект**. Скилл с 10 установками и 1 000 000 звёзд — не «популярный», а случайный.

---

## 1. Установка

```bash
# 1. Спецификация и доменная модель
npx skills add mattpocock/skills --skill to-spec
npx skills add mattpocock/skills --skill domain-modeling

# 2. Архитектура и embedded
npx skills add jeffallan/claude-skills --skill embedded-systems
npx skills add jeffallan/claude-skills --skill architecture-designer

# 3. Сервер (Python)
npx skills add mrgoonie/claudekit-skills --skill backend-development
npx skills add sickn33/agentic-awesome-skills --skill python-fastapi-development

# 4. Приложение (Kotlin / Compose)
npx skills add jeffallan/claude-skills --skill kotlin-specialist

# 5. Железо: BOM, батарея, питание, корпус
npx skills add wedsamuel1230/embedded-engineering-skills --skill bom-generator
npx skills add wedsamuel1230/embedded-engineering-skills --skill battery-selector
npx skills add wedsamuel1230/embedded-engineering-skills --skill power-budget-calculator
npx skills add wedsamuel1230/embedded-engineering-skills --skill enclosure-designer
```

Установка глобально (для всех проектов) — флаг `-g`, без подтверждения — `-y`:

```bash
npx skills add -g -y mattpocock/skills --skill to-spec
```

Проверка установленного:

```bash
npx skills list
```

## 5. Правила использования

1. **Один скилл — одна задача.** Не загружать все 14 скиллов в один сессионный контекст: они пересекаются по назначению и будут конфликтовать в инструкциях.
2. **Проверять факты.** `embedded-systems` и `power-budget-calculator` дают методику, а не числа для этого железа. Все числа в `ТЗ.md` §8 — расчётные, помечены как требующие замера.
3. **Аудит ≠ безопасность кода.** `Gen Agent Trust Hub: Fail` у `jeffallan` — это про качество упаковки метаданных, а не про вредоносный код. Проверено вручную: только markdown.
4. **Пересматривать список после R2.** Для Compose-разработки могут оказаться полезны `vitorpamplona/amethyst@compose-expert` (1 400) или `minimax-ai/skills@android-native-dev` (2 700) — решения принимаются по факту, когда UI станет сложнее двух экранов.
