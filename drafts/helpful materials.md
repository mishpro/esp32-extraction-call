## Цель проекта
Обеспечить простейшую доставку сообщения в телеграм (например) с отслеживанием процесса отправки
- предотвращение случайной отправки
- длительная работа без подзарядки
- зарядка через type-c

## Компоненты
- плата esp32 - содержит wifi-модуль
	- esp32 cp2102 type-c 38pin
- экран LCD, совместимый с esp32
	- модель SSD1306, 0.96"
	- default i2c address is 0x3C or 0x3D
- динамик
	- какие есть для есп ок без дополнительной платы?
- предохранитель
	- тумблер на вкл питания
- корпус и кнопка
	- 3D печать

## Pipeline (черновик, только для уточнения промта, не реализации)
1. Подключиться к вайфай
	1. вывести на экран ок, ошибка
	2. ошибку сопроводить звуком
2. Проверить доступность тг-бота
	1. ping бота, отправить ему время, бот это запишет (где?) - журнал включений устройства может быть запрошен
	2. вывести на экран ок, ошибка
	3. ошибку сопроводить звуком
3. Готовность, ожидание нажатия кнопки
	1. Вывести на экран крупно ARMED, мигает
	2. Звуковое сопровождение, негромко (подумать, не будет ли раздражать)
4. Нажатие кнопки
	1. Гарантия доставки - бот должен вернуть ответ!
		1. Пока не вернёт - вывести на экран "ждём подтверждение доставки...", timeout 30 сек
		2. timeout - проверка wifi, ping бота
			1. если последовательно обе ок, то "Попробуйте ещё раз".
			2. если не ок, то вывести соответствующую ошибку, сопроводить звуком
	2. Устройство готово принимать сообщение.
		1. Вывести "Keep calm. Ждём время прибытия от Мишгана..."
	3. Из бота отправить количество часов
		1. бот проверяет доступность устройства (а так можно вообще?)
		2. по кнопке или буквально /send_timer 3, где 3 - это 3 часа
	4. Бот получает количество часов и запускает таймер
		1. 03:00:00
		2. звуковое сопровождение (ну неее, будет бесить)
		3. По истечению времени, вывести "Мишган уже должен был приехать"
